Privacy and compatibility

The publishing URL stays on the iPhone. The playback URL stays inside the Worker and is never sent to viewers. Up to five short-lived viewer tokens are issued to devices with the temporary code. Media is encrypted in transit with WebRTC. Cloudflare relays the stream, so this is not end-to-end encrypted from Cloudflare itself. Anyone with the code can attempt to join. Apple always confirms screen sharing; enable Focus to hide notifications. DRM-protected video can be blocked by iOS.
